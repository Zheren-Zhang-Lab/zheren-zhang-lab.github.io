# Synthetic public demo data

Every value and identifier in this folder was artificially generated solely to
demonstrate and test the Growth Curve Analyser. These files do not represent a
real experiment and contain no experimental, participant, student, or private
research data.

The two instrument workbooks describe the same fictional 48-well experiment:

- wells A1-A3: `Demo_strain` grown in `Demo_medium` as replicates 1-3;
- wells A4-A5: matching `Demo_blank` wells;
- well A6: an explicitly unused demonstration well;
- all other plate wells: intentionally left without measurements or metadata.

Use either instrument workbook together with
`synthetic_growth_demo_metadata.xlsx` to exercise import, plate mapping, blank
correction, plotting, export, and parameter analysis.
